**FA Activity: Agentic AI Application Implementation** 

**Design, Develop and Demonstrate an Agentic AI Application for a Real-World Problem** 

**Group size:** 1/2 students 

**Marks:** 40 

**Mode:** Practical implementation \+ demonstration \+ viva 

**Technology:** Python / LangChain / RAG / APIs / CrewAI as applicable 

**Duration:** 12th October 16th to 2026 

Note: A basic LLM chatbot or simple prompt-based application will not be considered sufficient for this FA activity. The application must demonstrate agentic behavior through planning, tool use, retrieval, multi-step task execution, or autonomous decision/action selection. 

**Submission Requirements** 

**A. Title** 

**B. Architecture diagram** 

**C. Working Application** 

**D. Source Code** 

GitHub repository or ZIP. 

**E. Test Report** 

Minimum **5 test cases**. 

**F. Short Report** 

Suggested structure: 

1\. Introduction 

2\. Problem Statement 

3\. Objectives 

4\. Proposed Agent Architecture  
5\. Prompt Design 

6\. RAG Implementation 

7\. Tool/API Integration 

8\. Agent Workflow 

9\. Safety Mechanism 

10\. Results 

11\. Limitations 

12\. Future Scope
